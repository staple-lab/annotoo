# Annotoo 0.5.1

Annotoo releases now publish to npm straight from GitHub Actions, using npm trusted
publishing. Each version carries a provenance statement linking it to the workflow run
and commit that built it. There are no functional changes from 0.5.0.

```sh
npm install @staplelab/annotoo@^0.5.1
```

The tarball and the standalone browser script remain attached to this GitHub release.
